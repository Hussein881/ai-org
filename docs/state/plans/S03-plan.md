Produced by feature-dev code-explorer + code-architect (opus). G3 = ACCEPT-DEFAULTS.

## Where live calls run
- `app/gateway` is a plain library. `AIORG_GATEWAY_MODE=fake|live` (default fake). Fake mode: registry holds only FakeProvider. The api container and CI always run fake.
- Live calls run only on the host as user aiorg (the signed-in claude/codex CLIs and their credentials live there). docker-compose publishes postgres on 127.0.0.1:5432 (no root needed; S04's host worker needs it too). New `scripts/gateway-host.sh <cmd>` sources repo `.env` in a subshell, points AIORG_DATABASE_URL at 127.0.0.1, sets MODE=live, runs `.venv/bin/python -m app.gateway.cli <cmd>` or `-m app.workers.echo`; never echoes values.
- Without keys the session can run claude_cli and codex_cli live. API-key providers (anthropic_api, gemini_api, openrouter_free) need the not-yet-installed aiorg-worker unit (founder root step) because keys are root-only in /srv/aiorg/secrets. `scripts/run-worker.sh` runs the host echo loop and, if `var/smoke-requested` exists, `cli smoke --all` first.
- Container worker flag `AIORG_WORKER_ENABLED`; for the live demo `.env` sets it false so the host loop alone claims tasks (SKIP LOCKED prevents double claim regardless).

- `router.py` Gateway(session_factory, policy, providers, clock, is_build_active).complete(role, task_ref, prompt_parts, schema, data_class, budget_hint, purpose, allow_during_build): secret parts replaced; effective class = max(declared, parts); assemble then redact; per candidate: skip disabled/unavailable, refuse disallowed data class, skip claude_cli while build runner active, skip blocked/hard-limited (soft breach emits event), else reserve then call; RateLimited→mark+next; ProviderError/Malformed→next; end of chain: all refused→DataClassRefused, any quota skip→Queued(min reset), else AllRoutesFailed; every outcome emits usage.recorded; response redacted. Own sessions so ledger commits survive caller rollback. API cost = tokens×price; NULL tokens → NULL cost (cap math adds unknown_call_usd, not stored).
- `cli.py`: `smoke [--provider|--all] [--allow-during-build]`, one tiny public call per enabled provider, prints provider/outcome/tokens/latency only.
- Migration 0003: model_usage (provider, model, role, purpose, task_id, run_id, outcome CHECK, input/output_tokens NULL, cost_usd NULL, pricing_basis CHECK, latency_ms, error_kind, finished_at; indexes) and provider_quota (provider UNIQUE, blocked_until, last_rate_limit_at; 7 seed rows). 1. Data routing: the gateway enforces a hard-coded floor independent of policy YAML: gemini_api/openrouter_free accept `public` only; `secret` is never sent anywhere. Provider error bodies and raw responses are never stored or logged: only error_kind plus status code. Value-based redaction also covers URL-embedded credentials (`scheme://user:pass@`), base64/URL-encoded forms of known secret values, and DSN passwords.
